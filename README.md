# Industry-Paper-Daily

每天读一篇行业论文，用大白话讲透。给想入门的人，也给想快速跟上的人。

One industry paper a day, explained in plain language — for people who want to actually understand papers, not just cite them.

## 每篇怎么读

每篇笔记固定五段，读完不超过 3 分钟：

1. **一句话** — 这篇论文到底说了什么
2. **解决什么问题** — 不看这篇的话，为什么这事难
3. **方法翻成人话** — 核心思路，不堆术语
4. **关键数字** — 结果里最值得记住的 2–3 个
5. **跟我们有什么关系** — 对数据中心、AI 工程、生意的真实启发
